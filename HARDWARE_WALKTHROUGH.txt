PHASE 1 — BACKEND: MISSING ENDPOINTS
Status: DONE
============================================================

What was done:
  Added the two endpoints that cameras and master ESP32 have been
  targeting since day one but which never existed — every hardware HTTP
  call was returning 404. Also added three Python packages for image
  processing and OCR.

Files changed:
  requirements.txt
    - Added: easyocr>=1.7.0
    - Added: opencv-python-headless>=4.9.0
    - Added: numpy>=1.26.0

  app/api/v1/hardware.py
    - Added imports: PlainTextResponse, numpy, cv2, re
    - Added lazy OCR reader singleton (_ocr_reader, get_ocr_reader())
    - Added DeviceLogData Pydantic model (device: str, msg: str)
    - Added POST /log endpoint (HTTP 204, writes to logger, no DB)
    - Added POST /anpr/upload_raw endpoint (full OCR + auth + GateLog + WebSocket)

New endpoint details:

  POST /api/v1/hardware/log
    Called by: all 3 ESP32 devices via sendLog() on every event
    Auth: X-Hardware-API-Key header
    Body: { "device": "ESP32_MAIN", "msg": "some message" }
    Returns: HTTP 204 No Content
    Effect: logger.info only, no database writes
    Rate limit: 120 req/min

  POST /api/v1/hardware/anpr/upload_raw?gate_id=1
    Called by: entry camera (gate_id=1) and exit camera (gate_id=2)
    Auth: X-Hardware-API-Key header
    Body: raw JPEG bytes (Content-Type: image/jpeg)
    Pipeline:
      1. Decode JPEG with OpenCV
      2. Run EasyOCR (lazy-loaded singleton, gpu=False)
      3. Pick highest-confidence text detection
      4. Strip non-alphanumeric, uppercase -> clean plate_number
      5. If confidence < 0.85 -> log as IGNORED
      6. Query Vehicle table: plate + status IN (EN_ROUTE, ASSIGNED, FREE)
      7. Save GateLog row to database
      8. If GRANTED -> broadcast WebSocket to MANAGER + ADMIN roles
    Returns: plain text "GRANTED" or "DENIED" (not JSON)
             ESP32 uses response.indexOf("GRANTED") to parse this
    Rate limit: 60 req/min

ACTION REQUIRED:
  Run this command in your virtual environment before starting the server:
    pip install easyocr opencv-python-headless numpy

  Note: First call to /anpr/upload_raw will download EasyOCR model files
  (~100 MB). This is one-time only.

How to verify (curl commands):
  # Should return 204
  curl -X POST http://localhost:8000/api/v1/hardware/log \
    -H "X-Hardware-API-Key: your_key_here" \
    -H "Content-Type: application/json" \
    -d '{"device":"TEST","msg":"phase 1 check"}'

  # Should return 200 with plain text GRANTED or DENIED
  curl -X POST "http://localhost:8000/api/v1/hardware/anpr/upload_raw?gate_id=1" \
    -H "X-Hardware-API-Key: your_key_here" \
    -H "Content-Type: image/jpeg" \
    --data-binary @/path/to/plate_image.jpg

  # Should return 403 (no key)
  curl -X POST http://localhost:8000/api/v1/hardware/log \
    -H "Content-Type: application/json" \
    -d '{"device":"TEST","msg":"no key"}'

PHASE 3 — FIRMWARE: MASTER CONTROLLER
Status: DONE
============================================================

What was done:
  Updated sketch_apr7a.ino with three improvements:
  1. API key header so sendLog() calls stop returning 403
  2. Non-blocking gate timer replacing delay(4000) — ESP32 loop
     was previously frozen for 4 seconds per vehicle, making it
     unable to detect a second arrival or respond to anything
  3. NVS persistence so carCount survives power cuts and reboots

File changed:
  hardware/sketch_apr7a/sketch_apr7a/sketch_apr7a.ino

Changes made:
  - Added: #include <Preferences.h>
  - Added: #include "../hardware_config.h"
  - Removed: 5 hardcoded const char* variables (ssid, password,
             entryCamUrl, exitCamUrl, logUrl)
  - Removed: hardcoded maxCars=4, DETECT_CM, CLEAR_CM literals
  - Replaced with: MAX_CARS, DETECT_CM, CLEAR_CM, ENTRY_CAM_IP,
                   EXIT_CAM_IP macros from hardware_config.h
  - Added in sendLog(): http.addHeader("X-Hardware-API-Key", HW_API_KEY)
  - Updated both WiFi.begin() calls to use WIFI_SSID / WIFI_PASSWORD
  - Added 4 gate timer state variables:
      bool gateInOpen / gateOutOpen
      unsigned long gateInOpenTime / gateOutOpenTime
  - Added Preferences prefs global
  - In setup(): prefs.begin("garage", false) + restore carCount from NVS
  - In handleEntryGate(): replaced delay(4000) with millis() state machine
                          + prefs.putInt("carCount", carCount)
  - In handleExitGate(): same replacement
  - In loop(): added gate-close timer checks at very top before sensor reads

How non-blocking gate works:
  Old code: setGateIn(true); delay(4000); setGateIn(false);
            (entire ESP32 frozen for 4 seconds)

  New code: setGateIn(true); gateInOpen = true; gateInOpenTime = millis();
            Then in every loop() iteration:
            if (gateInOpen && millis() - gateInOpenTime >= 4000) {
              setGateIn(false); gateInOpen = false;
            }
            (loop continues running normally while gate is open)
